# VisAid-Real-Time-Obstacle-Detection-System-for-the-Visually-Impaired
VisAid is a real-time obstacle detection system that helps visually impaired people move safely. It uses a camera and an on-device AI model to recognize obstacles such as people, vehicles, furniture, stairs and curbs, estimate how far away they are, and warn the user instantly through vibration and audio cues.
